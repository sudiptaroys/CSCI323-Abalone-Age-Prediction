# Data, provenance and acknowledgements

## Dataset

`abalone.data` and `abalone.names` come from the [official UCI Abalone archive](https://archive.ics.uci.edu/static/public/1/abalone.zip), associated with [DOI 10.24432/C55C7W](https://doi.org/10.24432/C55C7W). UCI lists the dataset under [Creative Commons Attribution 4.0](https://creativecommons.org/licenses/by/4.0/). Attribute Nash et al. and the UCI repository when reusing the data. The CSV splits and scaled predictors are transformations of those data, not new independently collected observations.

## Earlier group experiment

This repository continues the earlier CSCI323 FT16 abalone experiment. Its original notebook organization, model settings and archived report results are acknowledged to the [prior group repository](https://github.com/tianyizhang789-star/CSCI323_Project_Group_FT16_Code). The new common module, runner and instructional notebooks implement that documented design; they should not be described as an unrelated, wholly new experiment. No original group membership, contribution percentages or present authorship assignments are asserted here.

The public prior repository did not include a license at inspection. It is linked for attribution; this repository does not grant a license to that third-party source code. The dataset's CC BY 4.0 license applies to the data, not automatically to every file in this repository.
